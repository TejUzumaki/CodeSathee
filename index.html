CODESATHEE

A no-bullshit, 100% client-side collaborative code editor. Write code, sync in real-time via WebRTC, and voice chat with your peer. No servers, no accounts, no logs.

How The Tech Works

1. WebRTC Data

Direct browser-to-browser connection. Keystrokes, cursors, and mouse tracks are sent as JSON payloads over the DataChannel with zero latency.

2. Media Stream

Voice channels use raw WebRTC MediaConnections. Mic audio is streamed directly to the peer. No central server processes your voice.

3. Local First

Your code is saved to localStorage. If you go offline, changes are tracked. When you reconnect, a smart sync resolves conflicts.
