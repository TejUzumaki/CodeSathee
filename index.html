CODESATHEE

A no-bullshit, 100% client-side collaborative code editor. Write code, sync in real-time via WebRTC, and voice chat with your peer. No servers, no accounts, no logs.

How The Tech Works

1. CRDT Sync

We use Yjs to sync operations, not full strings. This means no data loss or overwriting when two developers type at the exact same millisecond.

2. WebRTC Media

Voice channels use raw WebRTC MediaConnections. Mic audio is streamed directly to the peer with Voice Activity Detection (VAD).

3. Local First

Your code is saved to localStorage. If you go offline, changes are tracked. Snapshots are persisted locally for ultimate resilience.
